# Formalize scene transitions with fade (sceneManager.transitionTo)

## Problem
Scene switch happening between `g.pollHandlers()` and `scene:update()` = crash.
pollHandlers registers OLD scene's system handlers; if a fade callback swaps the
scene mid-frame (before scene:update), the new scene's ECS:update fires
"preUpdate" and the stale physics handler indexes a data table with no
physicsWorld -> nil crash (physics.lua:101).

Introduced by moving battle victory->map goto into a fadeToBlackService callback
(runs at main.lua:167, between pollHandlers @159 and sc:update @169).

## Invariant we want
A scene switch (gotoScene/enter + handler swap) must only happen at a frame
boundary: the TOP of love.update, BEFORE g.pollHandlers(). Never inside a fade
callback that runs mid-frame.

## Design (decided)
- KEEP g.gotoScene / sceneManager.gotoScene immediate (unchanged).
- ADD sceneManager.transitionTo(name, opts) helper that:
  - starts fade-to-black
  - on black complete, sets a PENDING switch (does NOT switch immediately)
  - a new sceneManager.applyPending() runs at TOP of love.update, does the real
    gotoScene at the safe boundary, runs opts.onSwitch, then starts fade-from-black.
- fadeToBlackService stays the dumb multi-fade renderer (already refactored).
- Fade durations centralized in consts, callers can override via opts.

## consts (new)
consts.SCENE_FADE = {
  OUT = 0.3,   -- fade to black
  IN  = 0.3,   -- fade from black
}
consts.RUN_START_FADE = 1.3         -- commander PLAY
consts.RUN_START_FADE_DEV = 0.1     -- dev override
(Keep it minimal; maybe just SCENE_FADE_OUT / SCENE_FADE_IN scalars.)

## sceneManager changes
State (module-local):
  local pending = nil  -- { name=, onSwitch=, fadeIn= }

function sceneManager.transitionTo(name, opts)
  opts = opts or {}
  local fadeOut = opts.fadeOut or consts.SCENE_FADE_OUT
  local fadeIn  = opts.fadeIn  or consts.SCENE_FADE_IN
  fadeToBlackService.fadeToBlack(fadeOut, function()
    pending = { name = name, onSwitch = opts.onSwitch, fadeIn = fadeIn }
  end)
end

function sceneManager.applyPending()
  if not pending then return end
  local p = pending; pending = nil
  sceneManager.gotoScene(p.name)
  if p.onSwitch then p.onSwitch() end
  fadeToBlackService.fadeFromBlack(p.fadeIn)
end
