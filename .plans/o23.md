ui.Box — simple 2-pass immediate-mode layout helper

PROBLEM:
Drawing backgrounds behind content requires knowing content size first.
Currently this means manual pre-measurement (font:getWidth, getWrap, etc) which is bloaty.

SOLUTION:
A small retained buffer that accumulates entries in pass 1 (measuring),
then draws bg + content in correct order in pass 2 (render).

API:
    local box = ui.Box(args, drawBg)
    box:addText(txt, font)
    box:add({ draw = fn(x,y,w,h), getHeight = fn() -> h })
    box:addSpacing(h)
    box:render(x, y)  --> returns totalW, totalH

args: { padding, spacing, maxWidth (required) }
drawBg: function(x, y, w, h)
Left-aligned only. Custom draw funcs can handle their own alignment.

INTERNAL:
    entries list, each: {type="text"|"custom"|"spacing", ...}
    render does:
      1. measure all entries (richtext.getWrap for text, getHeight() for custom, h for spacing)
      2. compute totalW (max entry width + padding*2), totalH (sum heights + spacing*(n-1) + padding*2)
      3. call drawBg(x, y, totalW, totalH)
      4. draw entries top-to-bottom at x+padding, y+padding+offset

KEY: richtext.getWrap(txt, font, maxWidth) -> (width, lineCount), already LRU cached.

FILES: src/ui/boxes.lua, src/ui/ui.lua (expose ui.Box)
